# Sicherheit und Datenschutz

## Geltungsbereich

Version 0.1.0 ist eine technische Quellcode-Vorschau für Windows 11.
Die Anwendung ist kein Sicherheitsprodukt. Geschützte oder nicht eindeutig
verifizierbare Ziele werden abgelehnt. API-Dienste können Kosten verursachen.

## Sicherheitsmeldungen

Bitte Sicherheitslücken vertraulich über GitHub Private Vulnerability
Reporting melden, sofern es für das Repository aktiviert ist. Andernfalls
zunächst nur um einen vertraulichen Kontaktweg bitten. Keine Schlüssel,
personenbezogenen Daten, Screenshots vertraulicher Inhalte oder
ausnutzbaren Details in öffentlichen Issues veröffentlichen.

Hilfreich sind Version, Windows-Version, betroffene Komponente und
reproduzierbare Schritte mit synthetischen Daten.

## Lokale und Cloud-Verarbeitung

Cloud-Freigaben sind pro Provider und Funktion getrennt. API-Schlüssel
nicht in Git oder Konfigurationsbeispiele eintragen. Bei Cloud-Nutzung
gelten auch die Datenschutz- und Nutzungsbedingungen des jeweiligen
Dienstes. Kein automatischer Wechsel von einem lokalen zu einem
Cloud-Provider. Manuelles Kopieren und Vorlesen ist eine separate,
ausdrücklich ausgelöste Funktion.
