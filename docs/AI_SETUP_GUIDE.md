# OMOI VoxBridge — AI-Assisted Installation and Customization

## 1. Назначение

Инструкция для установки, полной настройки, оптимизации и персонализации OMOI VoxBridge с помощью ChatGPT, Codex или другого ИИ-агента. Скопируйте содержимое файла в новый чат и предоставьте доступ к исходному коду проекта. При необходимости ИИ может адаптировать локальную копию программы под оборудование и требования пользователя, в том числе изменять исходный код.

## 2. Информация о проекте

- Windows 11, Python 3.11 x64, PySide6 / Qt.
- Лицензия исходного кода: MIT.
- Публичный репозиторий: https://github.com/drahulskyiandrii-cpu/omoi-voxbridge-public
- Функции: диктовка, STT, TTS, живые субтитры, перевод, OCR, анализ текста и изображений, локальные и облачные модели, глобальные горячие клавиши, MCP и системный трей.

Часть функций экспериментальна или требует отдельных внешних компонентов. Модели и ключи API не поставляются с исходным кодом.

## 9. Выбор оптимальной конфигурации

| Оборудование | Рекомендуемое направление |
|---|---|
| CPU без дискретной GPU | CPU, OpenVINO при совместимости, облако при согласии |
| Intel CPU / iGPU | Проверка OpenVINO |
| AMD GPU | Проверка совместимых локальных движков |
| NVIDIA 4–6 GB VRAM | Компактные модели |
| NVIDIA 8 GB VRAM | Оптимизированные локальные модели |
| NVIDIA 12–16 GB VRAM | Расширенный локальный режим |
| NVIDIA 24+ GB VRAM | Более крупные модели |
| eGPU | Динамическое управление устройствами |
| Ограниченная RAM | Минимизация одновременно загруженных моделей |
| Высокая конфиденциальность | Локальная обработка |

Это ориентиры, не гарантии. Подбор основан на реальных требованиях моделей, доступной памяти и измерениях.

- Local Mode: локальное выполнение поддерживаемых функций.
- Cloud Mode: только разрешённые внешние API.
- Hybrid Mode: сочетание локальных и облачных компонентов.

Не переключай локальные функции на облако без разрешения пользователя.

## 10. Установка основной программы

Проверь Python 3.11 x64. Из каталога исходного кода:

```powershell
.\Setup-VoxBridge.cmd
.\Doctor.cmd
.\Start-VoxBridge.cmd
```

Демонстрация субтитров без моделей и API:

```powershell
.\Demo-Untertitel.cmd
```

При необходимости используй независимую установку из проверенного Wheel по `docs/INSTALLATION.md`. Не изменяй глобальное окружение Python, если достаточно отдельного venv. Не переустанавливай совместимые компоненты без причины. Локальные движки и модели устанавливаются отдельно. При ошибках изучи диагностику, проверь зависимости и исправь конкретную причину.

## 11. Настройка STT

Изучи OpenVINO CPU, Faster-Whisper CUDA, OpenAI, Groq и возможные дополнительные движки. Проверь совместимость и качество для нужных языков, задержку, потоковую обработку, длинные записи, VAD, паузы, пунктуацию, выбор и сохранение микрофона, вставку текста, отмену и длительную стабильность. Используй существующие механизмы улучшения распознавания. Новые модели добавляй после проверки совместимости и сравнительных тестов.

## 12. Настройка TTS

Изучи Cartesia, Qwen3-TTS через совместимый Worker и другие движки при необходимости. Оцени языки, ударения, естественность, задержку до начала воспроизведения, скорость, RAM/VRAM, потоковое аудио, длинные тексты, остановку, выбор аудиоустройства, повторное использование и прогрев моделей, освобождение ресурсов.

Используй голосовые записи только с соответствующим разрешением. Не предполагай наличие локального Worker, адаптера или голосового профиля: они предоставляются и проверяются отдельно. Не отключай проверки совместимости ради запуска.

## 13. Настройка LLM

Изучи llama.cpp, llama-server, GGUF, OpenAI, Anthropic и другие варианты (например, Ollama при дополнительной интеграции). Учитывай RAM/VRAM, скорость, качество, языки, контекст, анализ изображений и приватность. Для локального анализа изображений проверь наличие совместимого проектора. Используй уже запущенные совместимые сервисы при явной конфигурации. Не завершай процессы других приложений и не загружай одновременно крупные модели без проверки ресурсов.

## 14. Настройка локальных компонентов

Пример переменных окружения (проверяй актуальные имена в документации проекта):

```powershell
$env:VOXBRIDGE_RUNTIME_ROOT = 'D:\SpeechRuntime'

# OpenVINO
$env:VOXBRIDGE_OPENVINO_SDK_DIR = 'D:\SpeechRuntime\openvino-sdk'
$env:VOXBRIDGE_OPENVINO_MODEL_DIR = 'D:\SpeechRuntime\whisper-medium-int8-ov'

# Faster-Whisper CUDA
$env:VOXBRIDGE_CUDA_PYTHON = 'D:\SpeechRuntime\cuda-venv\Scripts\python.exe'
$env:VOXBRIDGE_CUDA_MODEL_DIR = 'D:\SpeechRuntime\faster-whisper-small-ct2'
$env:VOXBRIDGE_CUDA_OVERLAY = 'D:\SpeechRuntime\faster-whisper-overlay'

# Local LLM
$env:VOXBRIDGE_LLAMA_SERVER = 'D:\SpeechRuntime\llama-server.exe'
$env:VOXBRIDGE_MODEL_DIRS = 'D:\SpeechRuntime\gguf'

# Qwen3-TTS
$env:VOXBRIDGE_QWEN_PYTHON = 'D:\SpeechRuntime\qwen-venv\Scripts\python.exe'
$env:VOXBRIDGE_QWEN_WORKER = 'D:\SpeechRuntime\qwen_server.py'
$env:VOXBRIDGE_QWEN_REFERENCE = 'D:\SpeechRuntime\voice.wav'
$env:VOXBRIDGE_QWEN_CF50_ADAPTER = 'D:\SpeechRuntime\adapter.safetensors'
```

Замени примеры реальными абсолютными путями. Указывай только нужные параметры. Проверь файлы, версии, модели, виртуальные окружения и библиотеки. Такие переменные действуют в текущей сессии PowerShell и её дочерних процессах; для постоянной настройки используй предусмотренный механизм или отдельный сценарий запуска. При `OPENVINO_WORKER_NOT_INSTALLED` проверь Node.js, SDK и модель. Следуй ограничениям совместимости Qwen Worker и адаптера из документации.

## 15. Настройка облачных API

| Переменная | Сервис |
|---|---|
| `OPENAI_API_KEY` | OpenAI |
| `GROQ_API_KEY` | Groq |
| `CARTESIA_API_KEY` | Cartesia |
| `ANTHROPIC_API_KEY` | Anthropic (опционально) |

Настраивай только необходимые сервисы. Не записывай ключи в код, Git, логи или чат. Не передавай пользовательские данные и не выполняй платные запросы без согласия. Разрешения для диктовки, озвучивания, анализа, системного звука и перевода должны контролироваться отдельно. Не допускай скрытого облачного fallback.

## 16. Настройка субтитров и перевода

Изучи WASAPI, потоковое STT, Overlay и перевод. Настрой языки, положение, размер, прозрачность, частоту обновления, промежуточные результаты, горячие клавиши и отключение там, где это поддерживается. Для локального перевода исследуй OPUS-MT, MarianMT, CTranslate2 и другие компактные решения. Предпочитай их крупным LLM, если качество и скорость достаточны. Локальный перевод может требовать разработки; не представляй экспериментальные функции как готовые.

## 17. Горячие клавиши и Windows

Проверь глобальные комбинации, независимость от раскладки, AltGr, конфликты, повторные нажатия, случайные активации и отмену. Стандартная диктовка — `Ctrl+Alt+Space` (проверь текущую конфигурацию). Тестируй Word, Outlook, Notepad, Edge, Chrome, Firefox, ChatGPT, Telegram, WhatsApp и другие приложения пользователя. Учитывай ограничения UI Automation и защищённых полей. Не обходи защиту. Для неподдерживаемой текстовой выборки используй документированный ручной вариант через буфер обмена, если он предусмотрен.

## 18. MCP

Изучи существующий MCP-интерфейс и поддержку ChatGPT, Codex, Claude и других клиентов. Текущая реализация предусматривает явную передачу текста через STDIO. Другие возможности могут потребовать разработки. Не предоставляй агентам автоматический доступ к экрану, микрофону и файлам без разрешения.

## 21. Качество кода

Соблюдай KISS, DRY, Separation of Concerns, модульность, понятные имена, типизацию, безопасную многопоточность и обработку исключений. Минимизируй зависимости, удаляй подтверждённый мёртвый код, избегай дублирования. Управляй ресурсами и процессами, сохраняй совместимость и не используй жёстко прописанные пользовательские пути, секреты и личные данные. Не переписывай весь проект ради локального исправления.

## 22. Оптимизация

```text
Input
  -> Audio / Text Capture
  -> Preprocessing
  -> Speech Recognition / Text Processing
  -> Translation / LLM
  -> Speech Synthesis / Text Output
  -> Target Application
```

Измерь время запуска и загрузки моделей, первый результат, распознавание, перевод, генерацию ответа и начало озвучивания, CPU/GPU/RAM/VRAM и фоновые процессы. Используй потоковую и асинхронную обработку, повторное использование сервисов, прогрев и контролируемое управление памятью, когда это даёт измеримый эффект. Сравни до и после. Не ухудшай качество ради незначительной скорости.

## 23. Стабильность и ошибки

Проверь недоступные и отключённые микрофоны/аудиоустройства/GPU, нехватку памяти, отсутствующую модель, недоступный сервер, неверный ключ, отсутствие интернета, сбой API, изменение настроек во время работы, закрытие приложения, недоступное выделение, смену окна, отмену и аварийное завершение Worker. Не допускай зависаний, потери данных, утечек памяти, неконтролируемых процессов и скрытого перехода на платные API.
